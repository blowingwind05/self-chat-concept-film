# 一个只和自己聊天的 App · 设想展示

标题是在说明这个想法是什么，项目尚未命名。

页面外壳采用黑白灰明亮主题，页头只保留“一个只和自己聊天的 App”文字标题。

这是一段固定 16:9、时长 1 分 49 秒的网页动画短片。画面按时间自动播放，不依赖滚动。切换采用局部滑动、卡片延续与直接剪切；故事中的固定背景、大标题与画框保持连续，不使用统一的全屏淡入淡出。加快汇入、连线、卡片与消息出现的动作，并压缩静止等待。聊天段为 7 秒，九条消息约每 0.68 秒到达，单条入场约 0.14 秒。文案和讲稿可直接作为长文字消息发送，文件传输另作示例。内容沿用原案的第一人称故事和具体例子，依次说明核心理念、常用操作、安全与隐私、初步技术设想及开发规划。

## 打开

直接打开 dist/index.html，或将 dist 目录交给任意静态服务器。

另附的“一个只和自己聊天的App-设想展示.html”把全部脚本、样式和原案图片嵌入同一文件，可独立保存并离线观看，无需安装或联网。

## 播放

- 默认开启轻音效，首次点击播放后出声；“静音观看”完全静音。
- 可暂停、拖动进度、跳转章节、全屏和重播。
- 空格或 K：播放/暂停；左右方向键：跳转 5 秒；M：静音；F：全屏。
- 切到后台会暂停，返回后由观看者继续播放。
- 画面始终为 16:9，不进行竖屏内容重排。

音效由浏览器 Web Audio 本地合成，包括轻消息声、纸感转场和稀疏和音；只有点击开启后才播放。没有旁白、外部音频、账号功能或信息收集。

传输光点按实际播放时间匀速移动，不受内容时间压缩影响。九合一沿曲线的等距离进度移动，避免缓入与曲线参数造成先慢后快。

核心理念一幕按实际播放秒重新编排：1.2 秒开始汇入，5.73 秒全部到达，5.85–8.55 秒完成窗口放大与文字展示，再接入具体消息。

汇入和消息展示共用同一套消息位置。消息随窗口按比例放大，随后在原位显示文字、图片和文件，不再收缩到下方或重新排布。

## 主要文件

- dist/index.html：播放器外壳、章节与文字稿。
- dist/film.js：按时间确定的 15 幕 Canvas 画面。
- dist/player.js：播放时钟和控制。
- dist/audio.js：本地合成的音效。
- dist/film.css：固定画幅与播放器样式。
- dist/assets/reference-architecture.png：从用户原案中提取的建筑摄影示例。

## 内容边界

页面展示希望实现的形态，相关功能尚待开发。安全部分明确区分初期保障、AI 数据处理与后续研究，不提前承诺端到端加密、零知识存储或已完成全面安全审计。
