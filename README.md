# 一个只和自己聊天的 App · 设想展示

GitHub Pages 预览地址：[https://blowingwind05.github.io/self-chat-concept-film/](https://blowingwind05.github.io/self-chat-concept-film/)。

源码入口：`dist/index.html`。仓库内可直接浏览完整 HTML、CSS、JavaScript 与媒体文件。

标题是在说明这个想法是什么，项目尚未命名。

页面外壳采用黑白灰明亮主题，页头只保留“一个只和自己聊天的 App”文字标题。

这是一段固定 16:9、时长 1 分 48 秒的网页动画短片。画面按时间自动播放，不依赖滚动。切换采用局部滑动、卡片延续与直接剪切；故事中的固定背景、大标题与画框保持连续，不使用统一的全屏淡入淡出。加快汇入、连线、卡片与消息出现的动作，并压缩静止等待。九种用途仍按原路径每 0.22 秒汇入；每条消息落位后停稳 0.04 秒，再在 0.14 秒内原位显示文字、图片或文件。之后的聊天段缩短为 2.5 秒，标题逐字波浪进入，说明文字和已出现的消息保持原位。文案和讲稿可直接作为长文字消息发送，文件传输另作示例。故事标题采用“不知道你有没有这样的习惯”，保持个人经历的表达。故事叙述集中在主文案，不使用跨区域续句；将多电脑切换登录与记录留存限制放在同一个画面，按个人使用经历明确说明微信、QQ 同一账号的电脑端只能一台在线。设备状态使用“当前登录 / 已下线”，指示点匀速来回两轮，与登录状态同步切换。微信的本地保存、备份迁移与 QQ 漫游的期限和范围为主要说明，飞书仅作为小字补充例子。笔记示例改为记录海报排版的灵感，出现分类选择后用两笔快速画出红色 ×，表达随手记灵感时不希望经过这些步骤。内容沿用原案的第一人称故事和具体例子，依次说明核心理念、常用操作、安全与隐私、初步技术设想及开发规划。

## 打开

直接打开 dist/index.html，或将 dist 目录交给任意静态服务器。

另附的“一个只和自己聊天的App-设想展示.html”把全部脚本、样式和原案图片嵌入同一文件，可独立保存并离线观看，无需安装或联网。

## 播放

- 默认开启完整立体声声轨，首次点击播放后出声；“静音观看”完全静音。
- 可暂停、拖动进度、跳转章节、全屏和重播。
- 空格或 K：播放/暂停；左右方向键：跳转 5 秒；M：静音；F：全屏。
- 切到后台会暂停，返回后由观看者继续播放。
- 画面始终为 16:9，不进行竖屏内容重排。
- 全屏画面使用完整视口，播放栏悬浮在底部；播放中闲置 1.8 秒后收起，移动鼠标或使用键盘即可唤出。暂停、操作播放栏或拖动进度时保持显示。

配乐采用 Scott Buckley 的《Origami》，按作者提供的 CC BY 4.0 许可署名使用。主体连续采用原曲前段，片尾在转场处接入原曲的收束段，通过交叉淡化与动作音效自然衔接。保留原速，调整整体音量与首尾淡入淡出。没有旁白或人声。动作音效保持轻量；文件发送改为短促柔和的轻触声，内容显露音随每条落位提前，删除重复落点声。窗口收拢音保持 0.6 秒。登录切换的前三次采用短促的张力拖动声，红色叉号按两笔绘制配以短摩擦声，六卡片转场以逐片掠过的声音衔接。

声轨预先渲染与混音，播放器以音轨时钟驱动画面，静音时也保持同步。暂停、拖动进度、重播均从对应位置继续；离线单文件内嵌全部声音和图片。无外部音乐服务、账号功能或信息收集。

完整混音为 44.1 kHz 双声道、256 kbps MP3，并保留原曲的段落变化。音乐署名、许可链接和修改说明同时位于网页、片尾与 dist/assets/MUSIC-LICENSE.txt。

传输光点按实际播放时间匀速移动，不受内容时间压缩影响。九合一沿曲线的等距离进度移动，避免缓入与曲线参数造成先慢后快。

云端与多平台段落各完成一次传输，到达后保持在云端端口，再切换画面；这些传输段落不加时。身份会话图使用居中账号、单次绘制的共享干线与电脑、手机、Web 三类会话。

核心理念一幕按实际播放秒编排：0.67 秒开始汇入，聊天窗口在 1.05–1.60 秒内完成放大；3.43 秒最后一条到达，3.61 秒显露完成。用途卡片飞离后整体退场，不保留空矩形或常驻引导线。每条飞行路径指向它到达时聊天框内对应消息行的中心，飞行图形在窗口上方绘制，最后一段航程逐渐变为目标消息的尺寸与样式，第 4.5 秒衔接下一幕。

汇入和消息展示共用同一套消息位置。消息在自己的行内落位，随窗口按比例放大，每条落位后立即在原位显示文字、图片和文件，不再等全部飞完后统一揭示，也不再收缩到下方或重新排布。

47–58 秒为一个连续画面：上一幕聊天窗口收小保留在左侧，消息先存入云端，再送入 AI，最后展开六张带有具体内容的信息卡。原始记录始终保留；传输以实际播放时间匀速完成，抵达后才显示相应结果。电影、待办、图片、单词、生活记录与检索示例都沿用前文。云端图标轻微上下浮动，AI 图标呼吸、处理点与扫描线持续运动。原消息逐条飞入云端，完成后恢复源消息，恢复完成后约 0.42 秒开始下一轮；共两轮，均在转场前全部抵达。流程图与常用操作之间使用逐元素遮罩滑动，顶栏稳定；聊天、云端、AI、连接与六张结果卡分别退出。压缩放大与等待后，整片缩短为 1 分 48 秒。

开场在 2.65–3.40 秒使用局部转场：标题逐行上滑，浮卡退开，聊天窗口去掉倾斜并扩展为故事画面，衔接“不知道你有没有这样的习惯”。顶栏保留，不使用全屏淡入淡出。

深浅底交替的四处使用刷色揭示：进入安全与开发规划时刷绿，进入隐私与结尾时刷白。笔刷边缘带细飞白，转场后恢复完整清晰画面。

## 主要文件

- dist/index.html：播放器外壳、章节与文字稿。
- dist/film.js：按时间确定的 15 幕 Canvas 画面。
- dist/player.js：播放时钟和控制。
- dist/audio.js：完整声轨的播放与同步。
- dist/assets/film-soundtrack.mp3：108 秒授权音乐与动作声立体声混音。
- dist/film.css：固定画幅与播放器样式。
- dist/assets/reference-architecture.png：从用户原案中提取的建筑摄影示例。
- production/：授权配乐剪辑与动作音效混音源码。使用 Python 3.12 安装 requirements.txt 后执行 `python production/mix_licensed_soundtrack.py`；它从作者官网下载原始音乐用于构建，中间文件保存在 .sound-build/，原始整曲不作为独立音乐交付。

## 内容边界

页面展示希望实现的形态，相关功能尚待开发。安全部分明确区分初期保障、AI 数据处理与后续研究，不提前承诺端到端加密、零知识存储或已完成全面安全审计。
